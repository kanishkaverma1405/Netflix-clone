# 🎬 Netflix Clone

A responsive Netflix-inspired landing page built from scratch using HTML5 and CSS3, focusing on modern UI design, responsive layouts, and clean frontend structure.

## 📌 Overview

This project is a frontend recreation inspired by the Netflix streaming platform. It was built from scratch using HTML and CSS to practice and demonstrate core frontend development concepts.

The interface includes a modern hero section, trending content cards, feature sections, FAQ area, and responsive layouts to create a polished streaming-platform experience.

## ✨ Features

- Netflix-inspired dark-themed user interface
- Responsive hero section with call-to-action elements
- Trending content cards
- "More Reasons to Join" section
- Frequently Asked Questions (FAQ) section
- Responsive layout for different screen sizes
- Clean and structured page sections
- CSS-based styling, positioning, spacing, and visual effects
- Interactive-looking UI elements and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Concepts Practiced

- Semantic HTML structure
- CSS Flexbox
- CSS Grid
- Responsive Web Design
- CSS Positioning
- Background Images and Overlays
- Typography and Spacing
- Card-based UI Design
- Hover Effects
- Section-based Layout Architecture

## 🎯 Project Objective

The objective of this project was to strengthen frontend development fundamentals by recreating a real-world streaming platform interface using HTML and CSS.

The project focuses on understanding how modern web pages are structured, styled, and made responsive without relying on pre-built UI components.
